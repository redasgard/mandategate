TITLE:
MandateGate — the payment firewall for AI agents (PayPal AI Hackathon demo)

DESCRIPTION:
MandateGate is a payment firewall for autonomous operations agents: an agent can prepare and submit vendor payment requests, but it can never grant itself the authority to move money. Every request is independently checked against vendor history, trusted destinations, policy limits and the original invoice document — then it either proceeds to PayPal, escalates to a human, or is denied.

What you'll see:
0:00 The problem: agents that can read invoices shouldn't be able to pay them
0:19 Invoice intake: a PDF is stored with its source hash; the AI reads it as an observation, never as authority
0:51 An operations agent submits three payment requests through the agent API
1:11 Request 1 → ALLOW: trusted vendor, normal amount
1:27 Request 2 → ESCALATE: unusual amount → human review with a mandatory written explanation (declined on camera; no payout)
1:50 Request 3 → DENY: the recipient was changed — blocked before any money could move
2:04 PayPal Payouts Sandbox: archived, verified payout evidence (clearly labeled in-video; this cut does not claim a live payout for the fictional invoice)
2:23 The result: every request lands in one auditable payment-decision ledger (AG Grid)

Built with Next.js, TypeScript, PostgreSQL (Neon), Drizzle ORM, Better Auth, the PayPal Payouts REST API (Sandbox), GLM-5.3 Flash for advisory invoice observations, AG Grid Community for the ledger, and Render for hosting. 572 automated tests; the demo was recorded on an isolated CI instance with payments disabled — sandbox only, no production money, ever.
