# PayPal AI Hackathon — binding rules extract

Source: https://paypalaihackathon.devpost.com/rules and https://paypalaihackathon.devpost.com/
Fetched: 2026-11-03. Full page text: `~/.hermes/profiles/product/cache/web/paypalaihackathon.devpost.com-dc2e3f99c5.md`

## 1. Dates

- Submission Period: Oct 1, 2026 (9:15 am PT) – **Nov 12, 2026, 12:00 pm PT** (hard deadline).
- Judging: Dec 1 – Dec 15, 2026. Winners announced ~Dec 21, 2026.

## 2. What to create (verbatim key phrases)

- "Entrants must build or update an application that integrates the PayPal developer platform (using the free sandbox environment) along with an AI tool, model, or platform of their choice."
- "PayPal integration is central to the project."
- New or existing projects allowed; existing projects "must have been significantly updated after the start of the Hackathon Submission Period" and the entrant "should explain how their Project was significantly updated."

## 3. Submission requirements (each is a pass/fail gate)

1. **Functional demo** — "judges must be able to actually run or interact with a working build", satisfied by
   "clear, complete setup and run instructions in your code repository … OR a hosted demo URL".
   "A design mockup, static prototype, or non-functional demo does not meet this requirement."
2. **Public code repository** (GitHub/Bitbucket/GitLab) — "must be public and open source by including an
   open source license file. This license should be detectable and visible at the top of the repository page
   (in the About section)."
3. **Demo video** — "<3 minutes", "must show the Project functioning on the device it was built for",
   "must be uploaded to and made publicly visible on YouTube", "must not include third party trademarks,
   or copyrighted music or other material" without permission.
4. **Text description** — "explain the features and functionality of your Project."
5. **Tools** — "identify which tools (model or AI service) were used and explain how the tools were used."
6. English materials throughout.

## 4. Judging criteria (Stage 2, equally weighted)

1. **Technological Implementation** — thorough/skillful use of PayPal Developer Platform + AI; genuine, working, non-trivial.
2. **Design** — "a complete, coherent product experience — not just a technical proof of concept."
3. **Potential Impact** — credible, specific case for a real problem + real audience; demonstrated.
4. **Innovation/Idea** — creative, novel, different from existing concepts.
5. **Presentation** — "Does the video clearly demonstrate the project working end-to-end? … what problem is
   solved, who it's for, and why it matters? … easy to follow?"

Stage 1: pass/fail — fits theme, applies required APIs/SDKs.

## 5. Prizes (relevant to MandateGate)

- Grand: 1st $12,000 / 2nd $8,000 / 3rd $5,000.
- Honorable mentions ($5,000 each): Most Creative, Most Impactful, Best Demo Delivery,
  **Best Use of PayPal + AI**, Best Use of Agentic Commerce.
- Sponsor prizes relevant to us:
  - **Best Use of AG Grid** — $5,000 (1st) / $2,000 (2nd) / $1,000 (×3), eligible = "All Eligible
    Submissions that use any AG Grid tools". MandateGate integrates AG Grid Community as the payment-decision ledger.
  - **Best Use of Render** — $1,000/$750/$500 Render credits, eligible = use any Render tools.
    MandateGate is hosted on Render.
- A project can win at most one Grand Prize + one Sponsor Prize, OR one Honorable Mention + one Sponsor Prize.

## 6. Traps checked

- Sponsor tools are optional ("using one of these partner tools is not required") but must be named + usage explained.
- No production PayPal: sandbox only (our rule: no production PayPal, ever).
- Third-party marks: PayPal UI references are expected in a PayPal hackathon; no music/assets in the video
  (narration is synthetic TTS; footage is our own product).
- Prefer no reliance on post-payout replay routes for judging: the functional-demo gate is satisfied by
  repo instructions (primary) + hosted URL (supplementary).
